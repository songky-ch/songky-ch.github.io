# 技术面试

这里独立收录与学习主题对应的技术面试专题.

- 开发视角: 原理、实现流程、接口契约、架构取舍、性能与故障处理.
- 测试视角: 风险覆盖、测试数据、判定标准、过程证据、故障定位与评测.

每道题包含考察点、回答结构、参考答案、递进追问和易错点. 教学案例与个人真实经历明确区分.

## 技术分类

- [Web 测试](./web-testing/): 从页面操作还原业务链, 用请求和数据建立证据.
- [接口测试](./api-testing/): 接口判定依据、业务断言与浏览器到 Postman 的复现.

- [Agent](./agent/): 从开发与测试视角考察智能体架构和业务执行闭环.

- [AI 评测](./ai-evaluation/): 从开发与测试视角考察 Agent、RAG 与大模型的评测设计和质量验证.
- [RAG](./rag/): 检索、融合、工具循环、证据契约与图关系的开发和测试面试.

需要先建立知识地图时, 可以回到[技术学习](../learning/)栏目.
