# 技术学习

这里按主题整理技术原理、框架机制、项目带读与实操流程.

每篇文档保留来源与适用版本, 结合图解、术语解释和练习验收. 涉及代码时区分教学伪代码、未执行示例和实际验证结果.

## 技术分类

- [质量工程](./quality-engineering/): 传统测试、业务数据质量与 Agent/RAG 评测, 结合光模块维护和生产实操.

- [Agent](./agent/): 通用与领域智能体的架构、工具执行、状态及结果验证.

- [AI 评测](./ai-evaluation/): Agent、RAG 与大模型的评测流程、指标、判定标准和质量验证.
- [RAG](./rag/): 检索增强生成的知识表示、召回、智能体控制与实现流程.

学习后可以进入[技术面试](../interviews/)栏目, 从开发与测试视角检验理解和表达.
