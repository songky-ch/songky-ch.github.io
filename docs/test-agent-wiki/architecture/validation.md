## 已完成的检查

- 本对话此前没有已生成 Wiki 或学习文章, 无历史产物需要迁移.
- 原始本地文档工作区不是 Git 仓库, 当时没有进行提交、建分支或公开发布; 本轮发布使用现有站点仓库.
- 只新增 wiki 目录产物, 未修改 sources 下同步资料或 AGENTS.md.
- 已检查 Markdown 本地链接与图片引用指向存在文件.
- 已检查 JSON 示例语法、围栏配对、分支 ID 连续性与需求/决策编号.
- 已解析 SVG XML, 检查图节点和连接引用, 实际渲染为 PNG 并查看.
- 已复核主流程、补问、拒绝、取消、未知结果与重试路径. 修正了未知结果直接视为成功、恢复跳过预检、部分文档绕过分支校验等图示问题.
- 已统一 Run 与 Task 状态的职责, 将业务结论、结果完整度和报告状态单独建模.
- 离线 HTML 进行结构、锚点与资源引用检查, 不加载外部脚本、字体或图片.

结构检查结果: 17 份 Markdown, 8 份 SVG XML 与 8 份 PNG, 2 个 JSON 示例, 85 个连续分支 ID, 17 个 HTML 章节, 错误数 0. 详细计数见 [检查结果 JSON](/images/test-agent-wiki/validation-results.json). 链接计数随检查记录自身新增链接更新, 以该结果文件为准.

## 验证限制

- SVG/PNG 已做桌面尺寸视觉检查, 未在实际 Windows 客户端或手机设备上验收. 宽图可查看原图, 不宣称已完成移动端可读性验收.
- 补充 Mermaid 内容保留为可编辑源码. 本轮未用 Mermaid 引擎编译; HTML 将其显示为可展开源码, 主要机制另有可直接查看的 SVG 图.
- HTML 未做跨浏览器视觉验收, Markdown 为权威源文档.
- 所有业务流程与 85 条场景都是设计, 未运行任何业务测试. 图文检查不等于工程测试通过.
- 未验证公司登录、凭证跨机器使用、模型网关、Linux 隔离和实际容量. 具体阻塞见 [决策表](01-scope-decisions.md).
- 官方资料核查始于 2026-10-26, 部分页面动态更新, 未锁定实际实施版本. Redis 官方页面读取超时已在参考章节注明.
