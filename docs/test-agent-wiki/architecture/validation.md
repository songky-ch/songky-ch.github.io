## v0.3 学习定位与交互演示

当前交付转为技术学习, 原 18 章作为案例保留, 新增 19 学习入口与 3 个交互演示标签页. 本次没有真实 Agent 后端或容器部署.

实际检查: 15 组已知算例/状态检查、96 种 RAG 配置、1,395 次状态转换、5 组 DOM 替身事件接线检查, 并检查参考答案标签不流入候选生成、忠实度不混同引用正确性. 记录与运行限制见 [演示检查记录](/demos/agent-lab/verification.json). DOM 替身不等于真实浏览器验收. 后续已在独立 Chrome 中完成 8 组交互检查 (含全部 96 种 RAG 配置), 并在同源 iframe 的 320/390/430 CSS 像素宽度检查三个标签页. 发现窄屏按钮竖排问题后修复并复测; 桌面深色、390px 深色与强制浅色样式截图已查看. 未在真实手机/Safari 或真实模型后端上测试.

## 验证限制

- SVG/PNG 已做桌面尺寸视觉检查, 未在实际 Windows 客户端或手机设备上验收. 宽图可查看原图, 不宣称已完成移动端可读性验收.

- HTML 未做跨浏览器视觉验收, Markdown 为权威源文档.
- 所有业务流程与 85 条场景都是设计, 未运行任何业务测试. 图文检查不等于工程测试通过.
- 未验证公司登录、凭证跨机器使用、模型网关、Linux 隔离和实际容量. 具体阻塞见 [决策表](01-scope-decisions.md).
