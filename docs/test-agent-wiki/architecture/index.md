# Agent 技术学习 Wiki (含架构案例)

版本: 0.3 / 技术学习版. 开始编写: 2026-10-26. 本次补充: 2026-10-27 (Asia/Shanghai).

当前目标: 通过文档理解 Agent 技术, 通过交互模拟理解机制, 以后有可核验记录再加入真实回放. 不再以完整企业项目上线为目标, 不需要先搭建服务器. 只有学习资料与教学页面, 尚无真实 Agent 后端.

原 01-18 章保留为架构案例, 可用于理解组件调用和故障边界. 原 Windows/WebView2、单服务进程、无 Docker 等约束只适用于历史案例. 多用户不等于每人必须长期占用一个 Docker 容器; 身份与数据隔离、执行隔离、资源限制和生命周期需要分开设计.

**学习从这里开始: [学习路线与隔离纠正](19-learning-guide.md) · <a href="/demos/agent-lab/index.html" target="_self">动态 HTML 实验室</a>.** 实验室包含 Agent 执行/审批、RAG 评测和 Agent 评测. 合成样例与程序实际计算明确区分, 不伪装真实模型执行.

阅读形式: 按章节在线阅读; [下载完整学习 Wiki v0.3](/downloads/test-agent-wiki-v0.3.zip) 包含 Markdown、离线阅读版、交互演示与检查程序.

## 设计约定

- **已确认**: 来自当前对话的明确要求.
- **建议基线**: 本 Wiki 提出的具体方案, 需要评审后才能冻结.
- **待验证**: 受公司环境、外部系统或实际运行约束影响, 文档不能替代验证.
- **教学示例**: 用于解释契约或指标, 不是可直接上线配置.

所有流程图描述建议设计, 不代表现有系统实现. “全部分支”限定为本版已定义的状态、业务选择和故障类别; 未知外部行为归入明确的阻塞或未知结果状态, 不宣称穷尽任何未来异常.

## 原项目如需落地, 仍需验证的五项

1. 登录信任链: 没有可申请的 IDaaS client_id 时, 公司是否存在获准的服务端身份验证途径.
2. Linux 执行边界: 能否配置 OS 级任务隔离, 而不只是启动同权限子进程.
3. 技术组合: WPF/WebView2 + React/TypeScript + Python/FastAPI/LangGraph + PostgreSQL/pgvector + Redis 是否接受.
4. 模型与算力: 内网模型是否支持工具调用、结构化输出、图片、Embedding 和评判; OCR 是否有可用算力.
5. 测试范围与指标: 目标系统、可用测试环境、压力上限、外部知识库接口以及脱敏样本文档是否明确.

这些问题统一记录在 [决策表](01-scope-decisions.md), 不要求现在一次答完.
